Adaptation notes:
The original falling-code character set, randomization, positions, speeds,
30 trails and fade behavior are retained. Trail colors are interpolated
between trans blue (#5BCEFA) and pink (#F5A9B8). The original vertex shader is
retained; the fragment shader is replaced with flat texture sampling on black.
TV distortion, static, scanlines, glitch, phosphor accumulation, and the
unrequested demo banners, icon images and full-screen color flashes are omitted.
The ReGL draw wrapper is replaced with direct WebGL calls because ReGL 1.3.9
uses runtime Function code generation, which conflicts with this site's CSP.
The unused onecolor/gl-matrix libraries are not bundled. Original
randomization credit is retained in source:
https://gist.github.com/blixt/f17b47c62508be59987b

The Inconsolata font is self-hosted separately under the SIL Open Font License;
see /licenses/inconsolata.txt. No Google Fonts runtime request is made.

Adaptation: polygon-sized neutral-center red/blue displacement map and split-channel filtering. React/native SVG replaces demo GSAP/Tweakpane. Cyan/pink dispersion and original TransProxy geometry retained.
