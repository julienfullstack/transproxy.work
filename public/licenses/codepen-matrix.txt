Adaptation notes:
The original character-trail functions and CRT shaders are retained. The
unrequested demo banners, icon images and full-screen color flashes are omitted.
The ReGL draw wrapper is replaced with direct WebGL calls because ReGL 1.3.9
uses runtime Function code generation, which conflicts with this site's CSP.
The fixed colors match the original onecolor/gl-matrix results; those unused
libraries are not bundled. Original randomization credit is retained in source:
https://gist.github.com/blixt/f17b47c62508be59987b

The Inconsolata font is self-hosted separately under the SIL Open Font License;
see /licenses/inconsolata.txt. No Google Fonts runtime request is made.
